# EduPredict AI — Student Dropout Prediction System

A cyberpunk-themed ML system predicting student dropout using 9 machine learning models.

## Features
- 9 ML Models: XGBoost, LightGBM, Gradient Boosting, Random Forest, Logistic Regression, SVM, KNN, Neural Network, Ensemble
- SHAP Explainable AI
- Mobile-responsive cyberpunk design
- UCI Dataset (4,424 students, 36 features)
